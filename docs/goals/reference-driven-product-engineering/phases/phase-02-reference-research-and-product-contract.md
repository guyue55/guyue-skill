# PHASE-02 参考研究与产品契约

- Goal ID：GOAL-REFERENCE-DRIVEN-PRODUCT-ENGINEERING
- 阶段 ID：PHASE-02
- 状态：就绪待执行
- 阶段目标：主动寻找适合的产品、案例和当前 Agent 工程经验，经必要用户澄清后冻结用于模拟的 B2B 工单产品快照与验收基线
- 稳定输入：PHASE-01 实验合同；用户批准的工单协作样本；最多 6 份一手或产品原始材料
- 依赖：PHASE-01 完成
- 本阶段改动边界：本 Goal reports、reviews、evidence；固定模拟的需求、设计与架构快照
- 本阶段不做：不复制品牌、文字、图片或专有资产；不编码产品；不安装参考产品代码
- 定向检查：来源日期、产品机制、适用场景、冲突、反向约束、用户决定和承诺 ID 双向对账
- 主线门禁：真实用户、核心工作流、角色权限、信息架构、技术边界、异常流、模拟输入和验收标准全部冻结
- 活体验收：未参与研究的审查者能从参考矩阵解释每个产品决定及不照搬项
- 失败处理：材料不足则使用下一候选；关键业务偏好不可推断则只向用户提一个最高影响问题
- 回滚方式：保留来源报告，撤销未批准的产品契约修订
- 人工检查点：确认会改变核心用户、角色、工作流或成熟度定义的业务选择
- 阶段完成条件：REQ-001、NREQ-002 有可复算证据，模拟快照可直接驱动两份独立专业报告
- 下一入口：PHASE-03 以冻结快照完成端到端模拟并选择唯一活体探针

## 工作项
- TASK-201：收集并比较当前 Agent 工程经验，以及 Linear、Jira、Intercom 或经证据替换的参考产品机制；一份材料指一个可独立访问的一手、官方或产品原始页面/文档，重复镜像只计一次
- TASK-202：提炼参考矩阵、反抄袭约束、模拟验收量表和差异化产品原则
- TASK-203：提出并关闭不可由项目事实推断的必要用户问题
- TASK-204：冻结需求、角色、权限、数据、界面、异常、技术约束和模拟快照
