# PHASE-03 预设模拟与最小活体探针

- Goal ID：GOAL-REFERENCE-DRIVEN-PRODUCT-ENGINEERING
- 阶段 ID：PHASE-03
- 状态：就绪待执行
- 阶段目标：在固定 B2B 工单产品情境上模拟参考研究后的产品、工程、多 Agent、评委回炉和恢复链路，并只对最大不确定点运行一个 35 分钟内的活体探针
- 稳定输入：PHASE-01 固定目标和预算；PHASE-02 冻结参考矩阵、必要问题与产品快照
- 依赖：PHASE-02 完成
- 本阶段改动边界：本 Goal reports、reviews、evidence；既有评测入口产生的临时或证据文件
- 本阶段不做：不构建完整产品；不改根控制面；不安装依赖；不运行第二个活体探针
- 定向检查：任务所有权、稳定输入、主控集成、外部检查器、停止门、恢复入口和探针命令退出码
- 主线门禁：GATE-001 的每一环节有现有 Guyue 入口或明确缺口；评委结论不只来自同模型偏好
- 活体验收：最高不确定环节有一次真实回放；不可运行时保留失败输出并降低结论等级
- 失败处理：模拟缺口直接记录；子任务无进展不续派；探针失败、不可运行或额度不足均保留 ATTEMPT，不自动重试
- 回滚方式：删除本轮临时产物；保留报告、命令、退出码和失败证据
- 人工检查点：模拟是否覆盖用户指出的“主动找参考、必要交互、多 Agent 协力和对照回炉”
- 阶段完成条件：REQ-002、REQ-003、REQ-004、RISK-002 有证据，且本阶段主动时间不超过 75 分钟；其中唯一活体探针不超过 35 分钟
- 下一入口：PHASE-04 读取全部报告并进行三路线裁决

## 工作项
- TASK-301：从产品与体验视角独立完成固定情境模拟
- TASK-302：从架构、权限、任务拓扑和检查器视角独立完成固定情境模拟
- TASK-303：独立评审组合模拟，找出最大证据缺口并指定唯一探针
- TASK-304：主控运行一次 35 分钟内的最小活体探针并登记命令、退出码、产物和结论边界
