# REV-0001 用户决定边界

- Goal：GOAL-REFERENCE-DRIVEN-PRODUCT-ENGINEERING
- 决定：批准以参考驱动、必要用户交互、多 Agent 协作和独立评审研究古月能力。
- 代表情境：中等复杂度 B2B 工单协作产品。
- 成本修订：不执行 8–16 小时的完整产品回放；改为最多 6 份外部原始材料的只读联网研究、固定情境模拟和最多一个最小活体探针。
- 主动执行上限：总墙钟最多 180 分钟；PHASE-01 20 分钟，PHASE-02 60 分钟，PHASE-03 75 分钟，PHASE-04 25 分钟。
- 材料计数：一份材料指一个可独立访问的一手、官方或产品原始页面/文档；重复镜像或同一来源的等价副本只计一次。
- Agent 调用边界：最多 3 个并行生产 Agent，各 1 个 turn；另加 1 个独立审查 turn。墙钟时间为硬上限，模型 turn 数另行记账但不扩大墙钟。
- 探针边界：唯一活体探针最多 35 分钟；失败、不可运行或额度不足时只保留 ATTEMPT，不自动重试。
- 已批准：本 Goal 控制、模拟、报告、证据写入；最多 6 份材料的只读联网；现有本地检查；一次 35 分钟内的最小活体探针；上述边界内的多 Agent 生产与独立审查。
- 未批准：安装或下载外部代码与资产；凭证、付费、部署、外部写入；修改 Guyue 根控制面；Git 暂存、提交、合并、推送或发布。
- 证据边界：本决定只授权 REV-0001 的低成本验证，不证明古月已具备成熟稳定产品构建能力。
