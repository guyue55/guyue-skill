# 固定产品契约 v1

- 产品名称：通用 B2B 工单协作系统（模拟名）
- 阶段：PHASE-02 冻结输入
- 生成时间：2026-07-30T18:35:00+08:00

## 用户与角色

| 角色 | 权限边界 |
|---|---|
| 管理员 | 管理用户、角色、状态配置、基础 SLA 参数 |
| 主管 | 查看团队工单、分派负责人、调整优先级、处理升级 |
| 处理人 | 查看分配给自己或所在团队的工单，更新状态、评论、内部备注 |
| 观察者 | 只读查看被授权工单 |
| 客户 | 只能看到自己的请求、公开评论和客户可见状态 |

## 首版对象

- 工单：标题、描述、来源、类型、优先级、状态、负责人、团队、客户、到期时间、创建时间、更新时间。
- 评论：公开评论与内部备注分离。
- 审计事件：创建、分派、状态变化、优先级变化、评论、重开、关闭。
- 视图：我的工单、团队队列、逾期风险、等待客户、已解决。

## 状态机

默认状态：新建 -> 待分派 -> 处理中 -> 等待客户 / 内部等待 -> 已解决 -> 已关闭。

允许重开：已解决状态收到客户回复可回到处理中；已关闭后创建跟进工单，不直接修改原工单。

## 首版验收标准

1. 创建工单必须进入新建或待分派状态，并写审计事件。
2. 分派必须绑定负责人或团队，权限由后端校验。
3. 状态转换必须受状态机约束，不能任意跳转到关闭。
4. 客户可见状态不得泄露内部等待、内部备注或私有审计。
5. 列表筛选必须来自真实数据查询或模拟数据源，不得只做前端假筛选。
6. SLA 风险至少能区分正常、临近、逾期三类。
7. 评论与内部备注在数据模型和界面上分离。
8. 所有关键动作可追溯。

## 非目标

- 不做完整 SaaS 多租户计费。
- 不做复杂自动化规则引擎。
- 不接入邮件、IM、CRM 或外部身份系统。
- 不生成品牌资产或复制参考产品视觉。
- 不声明已经构建成熟产品。
