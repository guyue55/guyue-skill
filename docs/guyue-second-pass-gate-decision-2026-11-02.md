# 全局二次复核门决策记录（2026-11-02）

状态：已落地（`dev` 分支，v1.8.0 候选载荷）
适用范围：`SKILL.md` 规则 7、`GUYUE_PRINCIPLES.md` 二次复核门、`scripts/test_claim_verification_guidance.py`

## 背景

需求是：把“二次复核”从可选技巧变成全局认知纪律——**每个实质问句和结论都要过第二遍**；但**不得限定复核方式**，否则会把模型判断力限死。同时要求交付后独立验证，且对每个结论再做一次复核。

这条需求本身存在张力：既要“每次都要复核”，又要“不许规定怎么做”。本记录说明我们如何在不限死方法的前提下，让“复核”不可被自我声明糊弄过去。

## 三个反复出现的失败模式

### 1. 同一标签，两套门槛

`已确认` 在原则文件写作“有当前证据直接支持”，在根规则写作“两遍具备判别依据”。两处都能自洽，但模型可以挑对自己有利的那份。

**结论**：状态定义必须收敛，且跨文件断言要覆盖状态本身，而不只是覆盖关键词。

### 2. 一刀切与比例原则互斥

“第二遍必须增加判别依据”若不加分层，就会与“低风险问题允许快速语义自检”冲突：一个定义类问题永远拿不到“新增判别依据”，结果是模型要么被迫把常识降级为 `推断`，要么虚构依据来合规。

**结论**：升级要求只适用于**可能被外部事实、计算、来源或高影响后果推翻**的结论；稳定知识、术语定义、用户给定前提的合格标准是逐项覆盖与无口径漂移。分层依据是“结论能否被推翻”，不是“任务类型”。

### 3. “保留原句 + 追加例外”无法被关键词测试防住

三轮修补都栽在这里。只要保留受保护的句子，再补一句“但……可升级为已确认”，关键词与句子集合比对都会放行。审查方用 7 组新变异证明当时的测试 7/7 未被捕获。

**结论**：结构测试的判定门换成**白化摘要**——去掉全部空白后对整段取 sha256，任何新增、删除、换序、用分号合并、改标点都会改变摘要，必须显式 `--update` 并审阅 diff 才通过。句子清单降级为失败时的可读 diff。

## 决定

1. **分层判据**：复核强度按“结论能否被推翻”分配；不给固定方法清单，方法由模型按任务自行选择。
2. **外部证据下限**：“模型之外”限定为原始来源、真实运行产物、接口响应、可核验第三方记录、人工验收。同模型分身、子 Agent、自审、换算法复算都不算；缓存响应、粘贴文本、其他模型输出也不算。外部数据上的计算仍属外部事实，复算不能替代取数；用户自己提供的输入不算外部事实。
3. **来源谱系**：转载、镜像、翻译、循环引用、同一数据集派生、同模型无新输入的重复回答只算一个来源家族，不能互相升级为确认。
4. **五态不变**：`已确认` / `推断` / `冲突` / `未知` / `决定`；用户给定事实记为 `推断` 并注明“用户前提、未独立核验”，不新增第六个标签；纯风格与偏好选择归 `决定`。
5. **高风险硬下限**：事实性结论不得只凭模型内部二遍封板；拿不到独立证据就显式降级；取舍类无外部证据时暂停并取授权，不用形式取证凑数。
6. **摘要回归门**：保护区域（`核心法则` 整段、`证据校准与可逆自治` 整段）以摘要锁定，改动必须显式批准。

## 被否决的方案

| 方案 | 否决理由 |
|---|---|
| 固定复核检查表 | 与“不要限死方法”直接冲突，且会把复核退化成填表 |
| 只做关键词/句子存在性断言 | 实测 7/7 语义削弱未被捕获；“保留原句 + 追加例外”无法防 |
| 句子集合相等（去重、排序） | 换序、用分号合并、短于 8 字的例外句都能绕过 |
| 只保护“二次复核门”小节 | 相邻规则（规则 4、证据充分即停）同样能削弱复核，形成盲区 |
| 把“独立复算/未参与产出的视角”算作模型之外 | 同模型换算法、同权重子 Agent 都能伪造“外部” |

## 后果与残余风险

- 摘要门约束的是**文档维护者**，不是模型的复核方式；核心法则任何措辞改动都要 `--update`，属有意审批点，长期有“习惯性 update”导致门退化的风险。
- 摘要忽略空白，`sub Agent` ↔ `subAgent` 之类的英文空格差异不可见。
- 静态门只证明**文本未变**，不证明模型照做。73 条行为合同中仅 3 条有 live replay 观测，本轮新增 4 条为 0；`run_eval` 如实输出 `required action execution 0/73`。
- “可定位来源”“新于被验证的变更”仍依赖人工或运行时判断。
- `release-payload.lock.json` 按整仓工作树取哈希，因此**中间功能提交的锁不自洽**（实测 `528e5e9` 校验失败，`6e2bb2c` 与 tip 通过）。发布只从最新 tip 构建。
