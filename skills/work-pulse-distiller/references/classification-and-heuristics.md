# 工作脉搏分类启发式与判定细则 (Classification & Heuristics)

本参考文档为 `work-pulse-distiller` 提供深度的分类决策启发式、指标提取规则以及状态灯升降级标准。

---

## 一、七大核心研发与业务维度分类法

在提炼【本周进展】时，自动根据日志内容的语义归入以下标准维度小标：

| 维度小标 | 涵盖场景与关键词 | 示例写法 |
| :--- | :--- | :--- |
| **架构与部署升级** | 云原生迁移、容器化、Cloud Run、VM/虚拟机、Swap 分区、负载均衡、数据库迁移 | **架构与部署升级**：系统成功从 VM 迁移部署至 Cloud Run，解决初始化与队列问题 5+ 项。 |
| **性能与查询优化** | 数据库索引、查询耗时降低、RAG 向量召回调优、冷启动优化、高并发支持 | **性能与查询优化**：重构工单列表索引与查询方式，列表加载效率提升显著。 |
| **核心功能与模块闭环** | 新功能上线、模块开发完成、从百分比推进至 100%、状态机流转 | **剪辑功能全流程闭环**：完成剪辑模块开发，支持剪辑、倍速、字幕与多格式导出。 |
| **UI/UX 与交互体验** | 页面重构、排版美化、拖拽置顶、三视图生成、中英文混杂修复、状态暂存 | **交互与体验优化**：导航栏支持拖拽与置顶，页面新增创作状态自动暂存。 |
| **稳定性与故障根治** | 内存溢出 OOM、Key 失效风暴、重试死循环、网络拦截、兜底机制 | **稳定性保障与 OOM 根治**：定位并解决虚拟机卡死，配置容器限额与 Swap 分区。 |
| **AI 智能化与算法拓展** | 飞书机器人问答、RAG 参数调优、剧本/分镜生成、自动化审计算法、多模态集成 | **AI 智能化拓展**：正式打通飞书机器人问答，调优 RAG 检索与上下文参数。 |
| **商业拓展与技术赛事** | 客户沟通、报价方案、高层决策推进、黑客松方案、创意调研、系统设计说明书 | **商务与需求推进**：完成两轮深入沟通，锁定首期数据监控需求并预约高层决策。 |

## 二、指标与定量数据聚合规则

1. **Bug / 修复项计数**：
   - 若出现 `修复和优化 2+`、`修复 3+`、`解决问题 5+`，在项目汇总时应合并表述为：`集中攻关并解决了 5+ 项关键问题` 或 `闭环处理 10+ 项潜在隐患`。
2. **百分比进度推进**：
   - 原始日志：`进度 60%` ➔ `开发完成` ➔ 提炼表述：`平台开发由 60% 快速推进至 100%，现已转入测试阶段`。
3. **资金与预算指标**：
   - 原始日志：`控制在十万以内` ➔ 提炼表述：`首期预算精准锁定在 10 万元以内`。

## 三、红绿灯状态判定与动态升降级矩阵

```
         ┌──────────────────────────────────────┐
         │ 原始日报输入 / 补充更新              │
         └──────────────────┬───────────────────┘
                            │
            ┌───────────────┴───────────────┐
            ▼                               ▼
   [是否存在严重阻塞/拦截/宕机?]    [是否达成重大里程碑/核心交付?]
      ├── 是 ──> 🔴 风险/阻塞/排查        ├── 是 ──> 🟢 正常/突破/上线
      └── 否                               └── 否
            │                               │
            └───────────────┬───────────────┘
                            ▼
               [处于方案设计/测试/沟通阶段]
                            ├──> 🟡 推进中/迭代中/决策中
```

### 降级与升级规则：
- **升级为 🟢**：当用户提交补充更新，说明原本正在“调试”或“排查”的问题已经彻底解决或功能闭环时，状态由 🟡 或 🔴 升级为 🟢。
- **降级为 🔴**：当核心流程出现外部强制拦截（如反爬阻断、权限被封禁、服务持续宕机无法自愈）且尚未找到兜底方案时，状态必须果断标 🔴 并提示风险。
